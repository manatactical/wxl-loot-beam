Stop hunting for the body you just killed. **Loot Beam** raises a pillar of light over every NPC corpse
that can still be looted, so the one worth walking to stands out from across the camp.

The beam is about 20 yards tall by default, breathes slowly so it looks alive, and has sparkles drifting
up through it. Terrain and walls hide it by default like anything else -- turn on **Through walls** if
you would rather see it through cover.

When you can, the beam is coloured by the best loot inside the corpse: green for a green item, purple
for an epic, and so on. Each quality can be recoloured, or switched off entirely, so you can skip the
uninteresting corpses and keep the rest.

Everything is adjustable live from the in-game **Loot Beam** panel, or from the `wxl-loot-beam.ini`
file next to the DLL. It is purely visual and entirely client-side: it sends nothing to the server and
changes no game data.

Optional: on servers running the companion **mod-loot-beam** server module, the beam gets its loot
colour the instant a body dies, before you open it. Without it, a corpse colours once you open its
loot window. The server half is not part of this install and must be set up by the server owner -- see
the README's **Server module** section.
